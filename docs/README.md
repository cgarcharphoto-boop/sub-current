# Subcurrent app prototype

Live: https://thedude0007.github.io/subcurrent-app-prototype/

A clickable prototype of a Subcurrent fan app and owner portal, built to sit alongside Multipass: timed location drops, push alerts, SoundCloud players for headliners, Multipass show links, a fan CRM, and flyer-to-show posting. It is one static page with no build step.

## What is real and what is demo

- Real: the Subcurrent logo art, Multipass show links and flyers, Multipass follower and event counts (October 2026), and the SoundCloud pages for MORBEATO, Shank Aaron, Basstroyd and SWANDO.
- Demo: show names, dates, prices, fans, sales numbers and the venue address. Lineups use Basscapital NYE artists as examples, not bookings.
- Simulated: payments, texts, AI flyer reading and the Multipass sync.

## Update the site

Replace `index.html` and commit to `main`. GitHub Pages republishes in about a minute.
